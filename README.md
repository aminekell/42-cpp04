# C++ Module 04 — Polymorphism

C++98 exercises in virtual dispatch, deep copying, abstract classes, and interface-based design.

## In this repository

- `ex00` — Compare polymorphic animals with classes that omit virtual dispatch.
- `ex01` — Give each dog or cat an independently owned Brain.
- `ex02` — Introduce an abstract animal base.
- `ex03` — Implement cloneable Materia, a character inventory, and a Materia source.

## Build and run

```sh
make -C ex03
./ex03/Materia
```

Each exercise has its own Makefile and executable. You can build any included exercise with GNU Make and a C++98-compatible compiler.
